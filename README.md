# Screendial — landing site

The public web version of the Screendial dashboard pages (Home, Sessions, Skills, Settings),
built with TypeScript + Vite. The UI is copied from the desktop app's dashboard; outside
Tauri it runs in browser preview mode, so desktop-only actions show a toast instead.

```sh
npm install
npm run dev      # local dev server
npm run build    # type-check and build to dist/
```
